Rollen verhindern zweierlei: dass alle alles können — und dass niemand etwas
kann. In einer Community gibt es fünf davon.

## Die fünf Rollen

| Rolle | Kurz gesagt |
|---|---|
| **Viewer** | Liest die Community und kommentiert mit |
| **Editor** | Verfasst Inhalte — moderiert aber nicht |
| **Moderator** | Moderiert Meldungen, Kommentare und Beiträge — verfasst aber nicht |
| **Admin** | Editor und Moderator zusammen, plus Design und Team |
| **Owner** | Admin, plus Übergabe und Löschung der Community |

Editor und Moderator sind **Geschwister**, keine Stufen: Wer schreibt, muss nicht
moderieren dürfen, und wer moderiert, muss nicht schreiben dürfen. Erst der
Admin vereint beides.

## Wer darf was

| Recht | Viewer | Editor | Moderator | Admin | Owner |
|---|:--:|:--:|:--:|:--:|:--:|
| Dashboard öffnen | ✓ | ✓ | ✓ | ✓ | ✓ |
| Beiträge verfassen | | ✓ | | ✓ | ✓ |
| Seiten bearbeiten | | ✓ | | ✓ | ✓ |
| Medien verwalten | | ✓ | | ✓ | ✓ |
| Events verwalten | | ✓ | | ✓ | ✓ |
| Kommentare moderieren | | | ✓ | ✓ | ✓ |
| Meldungen bearbeiten | | | ✓ | ✓ | ✓ |
| Beiträge moderieren | | | ✓ | ✓ | ✓ |
| Kurse verwalten | | | | ✓ | ✓ |
| Aktivitäten verwalten | | | | ✓ | ✓ |
| Design und Branding | | | | ✓ | ✓ |
| Team verwalten | | | | ✓ | ✓ |
| Community übergeben | | | | | ✓ |
| Community löschen | | | | | ✓ |

::note
Jedes Mitglied hat **genau eine** Rolle pro Community. Wer mehrere Communities
betreut, kann in jeder eine andere Rolle haben.
::

::note
**Rollen sind nicht der einzige Weg zu Rechten.** Wer lange und verlässlich
mitmacht, steigt in den
[Vertrauensstufen](/anleitung/produkte/diskussionen) auf und darf dadurch
zusätzlich etwas — private Nachrichten schreiben, später fremde Themen
aufräumen. Eine Stufe **nimmt nie etwas weg**; sie legt nur zu dem, was deine
Rolle ohnehin erlaubt.
::

## Was keine Rolle darf

Abrechnung, Plan und Zahlungsdaten gehören allein dem **Owner**: der Reiter
**Plan** in den Community-Einstellungen erscheint nur für ihn. Admin, Moderator
und Editor verwalten Inhalte und Team — nie den Vertrag. Siehe
[Abrechnung](/anleitung/abrechnung).

Ebenso sind instanzweite Dinge (Systemeinstellungen, Nutzerverwaltung über alle
Communities hinweg, Protokolle) dem Plattform-Betrieb vorbehalten und für
Community-Rollen nicht erreichbar.

## Wie jemand Mitglied wird

Deine Community steht unter `deinname.pukalani.app`. Wer sich dort anmeldet,
wird Mitglied — die Anmeldung läuft per Code an die E-Mail-Adresse, ein
Passwort ist nicht nötig.

Die Rolle **Owner** bekommt automatisch, wer die Community anlegt.

## Das Team verwalten

Unter **Dashboard → Community-Einstellungen → Mitglieder** erledigst du alles
selbst — vier Handgriffe:

| Handgriff | Was passiert |
|---|---|
| **Einladen** | E-Mail-Adresse und Rolle eingeben. Der Link gilt **7 Tage**. |
| **Rolle ändern** | Wirkt sofort. Dich selbst kannst du nicht herabstufen. |
| **Zugang entziehen** | Die Person kommt nicht mehr hinein — **Beiträge und Name bleiben stehen**. Zurück geht es nur per neuer Einladung. |
| **Besitz übertragen** | Macht jemand anderen zum Owner. Ein eigener, seltener Vorgang. |

Standardmäßig zeigt die Liste das **Team** (Owner, Admin, Moderator, Editor);
ein Klick zeigt **alle** Mitglieder.

::note
**Die letzte Owner-Rolle lässt sich nicht abgeben.** Eine Community ohne Owner
könnte niemand mehr verwalten — Pukalani verhindert das.
::

## Was du beim Verteilen beachten solltest

- **Sparsam anfangen.** Es ist leichter, Rechte zu geben als sie wieder
  zurückzunehmen.
- **Moderator statt Admin**, wenn jemand nur aufräumen soll — er kommt dann
  gar nicht erst an Design oder Team.
- **Owner bleibt bei dir.** Übergeben ist absichtlich ein eigener, seltener
  Vorgang.
